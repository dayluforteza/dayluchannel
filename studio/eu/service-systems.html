Daylu Forteza/Zerbitzuak/Sistemak

01

Ordenagailuak eta zerbitzariak ondo konfiguratuta.

Gaizki dabilen ordenagailu batek, erantzuten ez duen sistema batek edo konfigurazio oker batek zure lan guztiari eragin diezaioke. Windows, Windows Server eta macOS dituzten zure ordenagailuak berrikusi, konfiguratu eta optimizatzen ditut, eguneratuta, egonkor eta zure lanera egokituta egon daitezen.

Ezaguna egiten zaizu?

Hauek dira gehien iristen zaizkidan sistema-kasuak.

  1. 01Oraindik eguneroko lanerako prest ez dagoen ordenagailu berria
  2. 02Hainbat fitxa edo programa irekitzean motz geratzen den ordenagailua
  3. 03Eguneratu gabeko sistemak, software bikoiztuarekin edo lizentzia argirik gabe
  4. 04Karpeta, kanpoko disko eta kontu zaharren artean sakabanatutako datuak
  5. 05Agertzen ez diren edo behar bezala funtzionatzen ez duten inprimagailuak eta periferikoak

Zerbitzariak

Bulegoak konfiantza izan dezakeen zerbitzaria.

Windows Serverren instalazioa, konfigurazioa eta mantentzea: erabiltzaileak, fitxategi partekatuak eta bulegoak behar dituen zerbitzuak gordetzen dituen ekipo zentrala.

Zer barne hartzen duen

  • Windows Server instalatuta eta eguneratuta
  • Erabiltzaileak, taldeak eta baimenak pertsonaka
  • Karpeta partekatuak sarbide egokiekin
  • Zerbitzariaren kopiak programatuta eta egiaztatuta
  • Mantentzea eta egoera-berrikuspenak

Zurea izango da

  • Erabiltzaileen eta baimenen mapa
  • Kopia- eta leheneratze-proba
  • Administrazio-dokumentazioa

Zer barne hartzen duen

  • Datuak ordenagailu zaharretik migratuta eta egiaztatuta
  • Oinarrizko konfigurazio bera lanpostu bakoitzean

Zurea izango da

Sistema-zerbitzuak

Bulego bat talde gisa funtzionarazten duten zerbitzuak.

Pertsonak eta ordenagailuak lotzen dituzten zerbitzuen konfigurazioa: nork has dezakeen saioa, zein karpeta ikusten duen bakoitzak, nola banatzen diren helbideak eta izenak sarean (DHCP eta DNS), nola inprimatzen den, nora doazen kopiak eta nola konektatzen den bakoitza kanpotik.

Zer barne hartzen duen

  • Erabiltzaile-kontuak eta baimenak
  • Karpeta partekatuak eta sare-unitateak
  • Sareko inprimagailuak lanpostu bakoitzerako
  • Sare-zerbitzuak: DHCP eta DNS
  • Kopia automatikoak diskora, NASera edo hodeira
  • VPN bidezko sarbidea etxetik

Zurea izango da

  • Sarbideen zerrenda pertsonaka
  • Zerbitzuen konfigurazioaren laburpena
  • Eguneroko erabilerarako gida idatzia

Galderak

Sistemei buruz galdetzen dena.

Nire fitxategiak galtzen dira sistema berrinstalatzean?

Ez lukete galdu behar: segurtasun-kopia lanaren parte da. Edozein instalazioren aurretik zurekin berrikusten dut zer datu gorde behar diren, eta amaitzean egiaztatzen ditut.

Betiko programa erabiltzen jarrai dezaket?

Kasu gehienetan, bai. Softwarea zaharra bada edo sistemaren bertsio jakin baten menpe badago, hasi aurretik esaten dizut, alternatibak baloratzeko.

Windows, Windows Server eta macOSekin lan egiten duzu?

Bai. Egunero lan egiten dut Windows eta Windows Serverrekin, baita macOS ordenagailuekin ere. Kasu bakoitzaren irismena berresten dizut ezer ukitu aurretik.

Zenbat irauten du instalazio oso batek?

Datu-bolumenaren eta behar den softwarearen araberakoa da. Kasua berrikustean estimazio bat ematen dizut, hasi aurretik.
