Servidores

Um servidor em que o escritório pode confiar.

Instalação, configuração e manutenção de Windows Server: a máquina central que guarda os utilizadores, os ficheiros partilhados e os serviços de que o escritório depende.

O que inclui

  • Windows Server instalado e atualizado
  • Utilizadores, grupos e permissões por pessoa
  • Pastas partilhadas com os acessos certos
  • Cópias do servidor agendadas e testadas
  • Manutenção e revisões de estado

Ficas com

  • Mapa de utilizadores e permissões
  • Teste de cópia e reposição
  • Documentação de administração

Ideal para

Escritórios com vários postosNegócios que cresceram sem organizaçãoEquipas que partilham ficheiros

Sistemas operativos

Windows e macOS bem configurados.

Instalação e configuração do sistema operativo de cada computador, para que seja estável, esteja atualizado e pronto para o teu trabalho.

O que inclui

  • Instalação de raiz ou reparação de Windows e macOS
  • Atualizações, controladores e periféricos
  • Software instalado com licenças claras
  • Dados migrados e verificados a partir do computador antigo
  • A mesma configuração base em cada posto

Ficas com

  • Imagem base para os computadores novos
  • Inventário de software e licenças
  • Verificação dos dados após a migração

Computadores novosComputadores que ficaram lentosEscritórios que querem todos os postos iguais

Serviços de sistema

Os serviços que põem um escritório a funcionar como uma equipa.

Configuração dos serviços que ligam pessoas e computadores: quem pode iniciar sessão, que pastas vê cada um, como se distribuem os endereços e os nomes na rede (DHCP e DNS), como se imprime, para onde vão as cópias e como cada um se liga a partir de fora.

O que inclui

  • Contas de utilizador e permissões
  • Pastas partilhadas e unidades de rede
  • Impressoras em rede para cada posto
  • Serviços de rede: DHCP e DNS
  • Cópias automáticas para disco, NAS ou nuvem
  • Acesso por VPN a partir de casa

Ficas com

  • Lista de acessos por pessoa
  • Resumo da configuração dos serviços
  • Guia por escrito para o dia a dia

Ideal para

Escritórios pequenosClínicas e gabinetesEquipas em teletrabalho parte da semana

Perguntas

O que se pergunta sobre sistemas.

Perco os meus ficheiros ao reinstalar o sistema?

Não devias perder: a cópia de segurança faz parte do trabalho. Antes de qualquer instalação vejo contigo que dados é preciso manter e verifico-os no fim.

Posso continuar a usar o programa de sempre?

Na maioria dos casos, sim. Se o software for antigo ou depender de uma versão específica do sistema, digo-te antes de começar para avaliarmos alternativas.

Trabalhas com Windows, Windows Server e macOS?

Sim. Trabalho todos os dias com Windows e Windows Server, e também com computadores macOS. Confirmo o âmbito de cada caso antes de mexer em alguma coisa.

Quanto tempo demora uma instalação completa?

Depende do volume de dados e do software necessário. Dou-te uma estimativa quando revir o caso, antes de começar.
