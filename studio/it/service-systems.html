Computer e server configurati a dovere.

Un computer che funziona male, un sistema che non risponde o un’impostazione sbagliata possono rallentare tutto il tuo lavoro. Controllo, configuro e ottimizzo i tuoi computer con Windows, Windows Server e macOS perché siano aggiornati, stabili e adatti a quello che fai.

Sono i casi di sistemi che mi arrivano più spesso.

Domande

Le domande sui sistemi.

Perdo i miei file se reinstallo il sistema?

Non dovresti: il backup fa parte del lavoro. Prima di qualsiasi installazione verifico con te quali dati conservare e li controllo alla fine.

Posso tenere il programma che uso da sempre?

Nella maggior parte dei casi sì. Se il software è vecchio o dipende da una versione specifica del sistema, te lo dico prima di iniziare per valutare alternative.

Lavori con Windows, Windows Server e macOS?

Sì. Lavoro ogni giorno con Windows e Windows Server, e anche con i Mac. Ti confermo l’ambito di ogni caso prima di toccare qualcosa.

Quanto dura un’installazione completa?

Dipende dalla quantità di dati e dal software necessario. Ti do una stima quando esamino il caso, prima di iniziare.
