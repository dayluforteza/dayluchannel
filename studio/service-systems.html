Questions

Asked about systems.

Will I lose my files if the system is reinstalled?

They should not be lost: the backup is part of the job. Before any installation I check with you which data to keep, and I verify it at the end.

Can I keep the program I always use?

In most cases, yes. If the software is old or depends on a specific system version, I tell you before starting so we can weigh alternatives.

Do you work with Windows, Windows Server and macOS?

Yes. I work with Windows and Windows Server every day, and also with macOS. I confirm the scope of each case before touching anything.

How long does a full installation take?

It depends on the amount of data and the software needed. You get an estimate when I review the case, before I start.
